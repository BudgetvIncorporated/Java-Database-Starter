---
name: Shared library access policy
description: Owner-approved public viewer and sole-manager policy, separate from the school player model.
---

Keep catalog browsing and statistics public read-only; restrict changes, player details, saved-game management, and backup exports to the owner as the sole approved manager.

**Why:** The user explicitly selected public catalog access with only themselves as manager. Library players are school assignment data, not authenticated accounts.

**How to apply:** Never infer management access from a player record or grant it to the first sign-up. Preserve the four-table SQLite school model and the independent Java workflow when changing browser authentication.
